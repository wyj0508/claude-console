# Claude 控制台

一个基于 PyQt5 的桌面小工具，可以在窗口内直接和 Claude Code 对话，不需要打开终端。

- **界面内对话**：流式显示回复，工具调用以标签形式展示，对话记录实时可见
- **粘贴图片识别（新）**：在输入框直接 Ctrl+V 粘贴截图或拖入图片文件，
  控制台会用本地 OCR（RapidOCR / ONNX Runtime）把图片里的文字识别出来，
  随消息一起发给模型；输入框上方会显示缩略图、识别状态和识别字数，
  可随时移除。识别完全离线，不需要联网，也不依赖模型本身支持视觉输入。
  - 首次安装识别组件：
    `python3 -m pip install --user -i https://pypi.tuna.tsinghua.edu.cn/simple rapidocr-onnxruntime`
  - 其余依赖（numpy / opencv）本机已随 `python3-opencv` 安装
- **下载进度条（新）**：从 GitHub 安装技能时显示真实下载进度
  （MB / 百分比）、解压与安装步骤，并可随时取消；
  插件安装/卸载时显示进度窗口与已用时间
- **权限选择**：
  - `请求批准`：每次敏感操作（写文件、执行命令等）都弹窗询问
  - `帮我批准`：自动批准文件编辑，其他敏感操作仍会询问
  - `完全访问`：跳过所有权限确认（使用前会二次确认）
- **模型与思考强度（自动获取）**：
  - 模型列表在启动时向当前服务商自动拉取（读取 cc-switch 写入的
    `~/.claude/settings.json` 里的 `ANTHROPIC_BASE_URL` / token），
    并自动沿用 `[1M]` 等上下文后缀
  - 思考档位按服务商返回的 `supported_levels` 生成，下拉框直接显示英文原值
    （DeepSeek 当前为 `low / high / max`）；悬停可看到「服务商返回 N 档」及来源地址，
    状态栏也会显示本次拉取的来源与档位，便于确认不是内置兜底
  - 点击模型旁的 `↻` 可手动刷新；在 cc-switch 中切换服务商后，
    回到控制台窗口会自动重新拉取
  - 拉取失败时回退到内置的 DeepSeek Flash / Pro 列表
  - 对话中切换时会自动重建会话并保留上下文，选择会记住到下次启动
- **统一工作历史**：同时读取 `~/.claude/projects` 与 `~/.codex/sessions`，
  可按「当前项目 / 全部项目」和「全部来源 / Claude / Codex」筛选
  - Claude 会话双击后可在界面内恢复继续
  - Codex 会话双击后预览内容，并可转到终端执行 `codex resume`
- **引用回复（新）**：每条消息右上角有「↩ 引用」，点击后输入框上方会出现
  引用条；发送时会把你引用的原文一起带给模型，并在你的消息里显示引用摘要。
- **对话内直接显示图片（新）**：当回复里包含本地图片路径或 Markdown 图片
  （如 `~/桌面/图片.png`、`![](/path/a.jpg)`）时，控制台会直接在对话气泡里
  显示图片缩略图，点击即可打开原图，不再需要去文件夹里找。
- **主对话问答（新）**：在任意对话气泡里选中一段文字，右键选择
  「针对选中内容提问」，或点输入框下方的「针对选中内容提问」按钮，会打开
  悬浮问答窗（Ctrl+Shift+W 可随时召回）。也可以直接点「问答窗口」按钮，
  **不必先选中内容**，直接输入问题即可；若已选中文字，问题会自动带上引用。
  回答可一键「插入对话」，交互与研读页的解释栏问答一致。
- **生图 / 生视频（新）**：
  - 对话页顶部「生成 ▾」可直接生成图片或视频；也可以直接在输入框输入
    `/img 描述`、`生成图片：描述`、`/video 描述`、`生成视频：描述`。
  - 生成结果会以缩略图卡片显示在对话里，文件保存到
    `<项目>/.claude-console/generated/`。
  - 研读页的「生成配图 / 生成视频」会按当前研读主题或选中内容生成，
    结果显示在解释栏下方，并随研读记录一起保存。
  - 图片由共享技能 `media-tools` 调用 Agnes / SenseNova / SiliconFlow；
    视频可选 SiliconFlow（`siliconflow_video.py`，模型 MiniMax-H3）或 Agnes。
    需要在 `~/.dsh/secrets/media-tools.env` 配置服务商 Key
    （`AGNES_API_KEY` / `SENSENOVA_API_KEY` / `SILICONFLOW_API_KEY`）。
  - **一把 Key 同时生图和生视频**：推荐 SiliconFlow。图片用
    `Kwai-Kolors/Kolors`（官方定价免费），视频用 SiliconFlow 的
    `/v1/video/submit` + `/v1/video/status`（按次计费）。
  - 已部署的媒体相关技能：`media-tools`、`vision-review`、`atlas-cloud`、
    `seedance-2-5-skill`、`universal-video-prompt-skill`、
    `handdrawn-tech-illustrations`、`gpt-image-2-style-library`、
    `web-artifact-designer`。
- **技能与插件管理**：
  - 技能库：从 GitHub / 本地文件夹安装、删除、打开目录、同步到两端
  - **分类管理（新）**：技能按「生图 / 视频」「PPT」「开发 / 代码」「设计 / 网页」
    「其他」分组显示，顶部可按分类筛选；右键技能可手动修改分类。
  - 插件：Claude 与 Codex 并排管理，支持安装、启用/禁用、卸载
- **代码研读页（新）**：
  - 在「对话」页勾选 **研读模式** 后，主对话框的提问会自动切到「代码研读」页，
    并把 Claude 的回答写入左侧解释栏；回答里的代码位置会变成链接。
  - 左侧是 AI 解释栏，右侧是带行号的源码栏。点击解释里的 📄 链接，
    右侧会自动切换文件、滚动到目标块的起始行，并用高透明度淡蓝色标出目标行。
  - **VS Code 风格的多页源码**：打开过的文件会保留为页签，可自由切换、
    拖动排序或点 × 关闭；支持「← / →」在访问过的代码位置之间前进后退。
  - **代码目录树**：右侧可显示项目目录（自动隐藏 build、.git、node_modules 等），
    双击文件即可打开；可用「目录」按钮显示/隐藏。
  - **语法高亮**：使用本机 VS Code 的 Cute Pink Light Theme 配色
    （注释绿、关键字蓝、字符串暗红、类型蓝绿、函数棕、数字绿）。
  - **独立窗口（按项目各自独立）**：研读页默认是主窗口页签，也可以点「独立窗口」
    或对话页的「独立窗口」开关，把它放到单独窗口和主对话框并排使用。
    每个项目都有自己的研读页和独立窗口：主窗口在项目之间来回切换时，
    已弹出的窗口不会被切走或覆盖，多个项目的窗口可以同时开着、互不影响；
    窗口标题会显示所属项目名，关闭窗口会自动收回该项目自己的页签。
  - 解释栏支持两种对话方式：
    1. 主对话框继续总体学习（研读模式）；
    2. 在解释栏选中一段文字 → 点「针对选中内容提问」→ 在下方独立的问答框中追问，
       回答只进入问答区，不会覆盖解释原文。
  - **研读记录（新）**：顶部「保存研读 / 载入研读 / 返回刚才」把解释栏、局部问答
    和生成的配图/视频保存成记录，之后可随时载入或回到上一份研读。
  - **按项目独立记忆**：每个项目的「研读模式」开关、当前主页签（对话 / 代码研读 /
    会话历史…）、解释栏内容、局部问答和配图各自独立。切到别的项目不会把研读模式
    或页签带过去；切回原项目时会自动恢复它自己的模式和内容，不会被清空。
  - **精确跳转**：研读请求会自动附带项目的「符号索引」（真实文件 + 真实行号）。
    链接格式支持 `[[code:相对路径:起行-止行|函数或类名]]`，其中符号名用于校验：
    模型行号估算偏了时，会自动定位到该函数/类的真实定义块；同名文件分布在多个
    模块时，也会优先选择真正包含该符号的文件。
  - 每次局部问答的**最底部**会直接显示「添加到解释栏 / 删除」按钮，
    不再弹窗询问。
  - 顶部可载入任意 Markdown 讲解文件；不再内置某个特定工程的示例。
    代码跳转按当前项目的相对路径解析，适用于其他算法/工程代码。
- **项目列表**：常用目录一键切换，支持打开文件夹 / 终端 / VS Code
- **运行命令**：常用 shell 命令在外部终端执行，支持历史补全和收藏
- 白粉配色，F5 刷新会话列表

## 与 Codex 共享

- **技能库**：实体存放在 `~/.agents/skills`，并软链接到
  `~/.claude/skills` 与 `~/.codex/skills`，安装一次两边都能用。
- **工作历史**：`~/.agents/history` 下提供 `claude-projects` 与
  `codex-sessions` 两个只读入口；控制台的「会话历史」把两边合并展示。
- **插件**：Claude 插件使用 `.claude-plugin`，Codex 使用 `.codex-plugin`，
  格式不兼容，因此不做目录互链，只在控制台中统一管理。
- 已在 `~/.claude/CLAUDE.md` 与 `~/.codex/AGENTS.md` 写入共享入口说明，
  两边的 AI 新会话都知道去哪里查找对方的历史。
- 详细说明见 `~/.agents/README.md`。

## 运行

```bash
./run.sh
```

或安装到应用菜单（已创建）：

```bash
cp claude-console.desktop ~/.local/share/applications/
```

## 依赖

- `python3-pyqt5`（本机已安装）
- `vendor/` 目录内的 `claude-agent-sdk`（已随项目安装，请勿删除）
- 图片文字识别：`rapidocr-onnxruntime`（已安装到用户目录；模型随包离线携带）
- `numpy` / `opencv`（本机已有 `python3-opencv`）
- Claude Code CLI（本机通过 nvm 安装；程序会自动在 `~/.nvm/versions/node/*/bin`
  等常见位置查找，即使从桌面启动时 PATH 不完整也能工作）

## 说明

- 对话使用 `claude` CLI 的非交互流式接口，登录状态沿用你现有的 Claude Code
  配置；模型与思考强度可在对话页顶部直接切换。
- 会话 ID、历史记录与终端里运行的 Claude Code 完全一致，可以互相恢复。
- 若升级 `claude-agent-sdk`，请重新安装到 `vendor/` 目录。
